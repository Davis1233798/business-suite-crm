# 實作與驗收對照

本文件依 2026-10-30 原始碼與測試內容整理。`docs/PLAN.md` 是目標規格；測試檔名中的 `R01-R08` 等名稱不代表每個編號下所有條件均被檢查。

狀態定義：**已實作／局部測試**表示有可操作功能及列出的局部不變量測試，尚非整條規格全驗收；**部分**表示服務或畫面僅覆蓋部分要求；**待驗證**表示需另行操作／環境證據；**待實作**表示沒有完整功能。最終測試數、建置與部署結果以本次執行報告為準，這份對照不把未執行的整套檢查預先標成通過。

## 通用與首頁

| 規格 | 實作／證據 | 邊界及待辦 |
|---|---|---|
| C01 身分角色 | 部分；`p0-core` 驗證角色拒絕、`security-concurrency` 驗證 header 不能偽造身分 | 展示角色可自行切換，沒有正式登入／登出工作階段或企業 RBAC，不能標完整驗收 |
| C02 組織隔離 | 已實作／局部測試；cookie sandbox、服務 SQL organization 條件、`p0-core` 及 `security-concurrency` | 尚非所有端點逐一跨租戶滲透測試；不存在正式組織邀請授權 |
| C03 稽核 | 部分；有 audit_events 與部分操作紀錄，`p0-core` 檢查寫入 | 未涵蓋所有變更前後值、不可竄改儲存及企業留存政策 |
| C04 輸入／匯入 | 部分；關鍵數量、金額、表單及部分 Zod 驗證 | 未實作通用 CSV 匯入預覽、錯誤列下載；未完整測超長／重複鍵矩陣 |
| C05 持久化／備份 | 部分；D1 持久化、`p4-backup-csv` 三表摘要備份與獨立 SQLite 還原核算 | 不是全庫備份，沒有公開備份 UI／API；重啟後完整資料核對待環境驗證 |
| C06 併發／重送 | 已實作／局部測試；POS、Shop、Dining 原子 batch、重送唯一鍵與真實並行測試；CRM conversion 並行測試 | 不代表所有服務、所有失敗時點均具同等證據；未有雲端壓測 |
| C07 UX／無障礙 | 部分；表單、載入／錯誤回饋、響應式網格 | 375／768／1440 與全鍵盤／螢幕閱讀器矩陣待驗證 |
| C08 CSV／報表 | 部分；金額工具、日報／試算表；`p4-backup-csv` 公式轉義與台北格式測試 | 未有完整篩選後畫面／API／CSV 同步匯出鑽取流程 |
| C09 部署／健康 | 已實作；`/api/health`、DB binding、migration、request_id | 部署成功須原生工具回傳證據，文件不預設成功；日誌無秘密與新環境重建仍需實測 |
| F01–F03 首頁／作品／案例 | 部分；首頁提供六個實際系統入口與案例資訊 | 未提供本人姓名／經歷；非虛構履歷。未完成項目不得包裝為已驗收成果 |
| F04 導覽／深層路徑 | 已實作八個頁面路由及導覽 | 直接開啟、刷新、手機／鍵盤完整操作須瀏覽器實測 |
| F05 訪客空間／重置 | 已實作 cookie 組織與自己的 seed reset，隔離服務有測試 | reset 的全瀏覽器流程與同時 reset／寫入衝突未完整驗證 |
