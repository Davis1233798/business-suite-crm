# ForgeFlow 製造管理 開發範本

狀態：依用戶最新要求改為 SAP 風格高密度工作台，實作與驗證紀錄見下方。路徑：`/mes`。

## 模板來源與選型

原始參考：[本地 SAP DESIGN.md](../references/sap/DESIGN.md)。來源版本見 [manifest](../manifest.json)。

以 SAP 企業工作區的灰色框架、藍色選取、平面表格與緊湊操作呈現生產資訊；不使用 SAP 官方標誌或專有字型。

## 頁面骨架

緊湊頁首 → 六項真實累計摘要 → 工單表與報工側欄 → 並排物料／報工表 → 投入追溯、品檢、工作中心 → 生產作業表單 → 折疊 OEE 測試範例

桌面：工作內容與操作側欄並排，主要內容可收縮（min-width: 0）；表格在自己的容器水平捲動。平板：摘要與工作區適度換行。手機：單欄，操作摘要接續內容，不遮住表單及確認按鈕。

## 元件清單

- `WorkOrderTable`
- `StatusBadge`
- `ProgressMeter`
- `ProductionReportForm`
- `TraceabilityPanel`

## 視覺規則

- 主操作 `#0057d2`；底色 `#f5f6f7`；內容表面 `#ffffff`。
- 數字使用 tabular-nums；密集表格 12px、正文 13px、次要欄位 11–12px；桌面控制項 32px，觸控裝置至少 44px。
- 採明亮表面、灰色表頭與細分隔線，藍色用於主操作及選取；綠色只標示良品／放行。
- 使用共用語意色及可見鍵盤焦點。字體採系統中文字體；不得依賴來源品牌專有字型。

## 業務保留條件

保留 BOM、下達、領退料、開工、報工、品檢、停機及 OEE；報廢與警告需文字及圖示。

## 實作定位

`app/mes/page.tsx; app/mes/mes-workbench.module.css; components/domain-operations.tsx`

從頁面區域設定 data-site="mes"，於該區域定義 CSS custom properties；共用按鈕／表單讀取區域 token。禁止用全域色碼取代把其他站台改色。所有 API、資料模型、金額規則與角色處理沿用現有實作。

## 驗收條件

- 360、768、1440px 寬度逐一截圖；無頁面級橫向溢出，表格可在容器捲動。
- 鍵盤可操作分頁、表單和主要操作；焦點可見；標籤、錯誤訊息可被輔助工具辨識。
- 載入、無資料、API 錯誤、送出中、成功及唯讀拒絕均有清楚呈現。
- 一般文字對比至少 4.5:1；大型文字與控制項邊界至少 3:1；狀態必須搭配文字。
- 走完本範本業務保留條件中的核心流程；執行 TypeScript、既有相關測試與正式建置。

## 開發指令範本

> 閱讀本文件、共用規範及本地原始參考。先沿現有狀態與資料契約拆出上述元件，再套用區域 token 與響應式骨架。完成各種操作狀態、鍵盤及三種尺寸的畫面驗證。回報實際驗證結果，未實測項目明確標記。
