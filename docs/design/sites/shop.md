# MarketLane 電商前台 開發範本

狀態：已完成本地 UI/UX 實作；實際驗證範圍見 [實作紀錄](../IMPLEMENTATION.md)。路徑：`/shop`。

## 模板來源與選型

原始參考：[本地 nike DESIGN.md](../references/nike/DESIGN.md)。來源版本見 [manifest](../manifest.json)。

Nike 的商品優先、黑白交易介面與清楚規格選擇適合獨立購物前台。

## 頁面骨架

品牌／分類與搜尋 → 商品網格｜購物車 → 規格／庫存 → 配送與優惠 → 訂單與付款

桌面：工作內容與操作側欄並排，主要內容可收縮（min-width: 0）；表格在自己的容器水平捲動。平板：摘要與工作區適度換行。手機：單欄，操作摘要接續內容，不遮住表單及確認按鈕。

## 元件清單

- `ProductGrid`
- `ProductCard`
- `VariantPicker`
- `CartSummary`
- `CheckoutForm`
- `OrderHistory`

## 視覺規則

- 主操作 `#111111`；底色 `#ffffff`；內容表面 `#f5f5f5`。
- 數字使用 tabular-nums；正文 14–16px；次要文字至少 12px；觸控操作至少 44px。
- 不使用 Nike 標誌、品牌文案、專有字體或無授權照片；無商品圖時保留中性占位，不暗示真實商品影像。
- 使用共用語意色及可見鍵盤焦點。字體採系統中文字體；不得依賴來源品牌專有字型。

## 業務保留條件

保留分類搜尋、規格、購物車、SAVE10、運費、地址、庫存保留、模擬付款與購後評價。

## 實作定位

`app/shop/workspace.tsx (management=false)`

從頁面區域設定 data-site="shop"，於該區域定義 CSS custom properties；共用按鈕／表單讀取區域 token。禁止用全域色碼取代把其他站台改色。所有 API、資料模型、金額規則與角色處理沿用現有實作。

## 驗收條件

- 360、768、1440px 寬度逐一截圖；無頁面級橫向溢出，表格可在容器捲動。
- 鍵盤可操作分頁、表單和主要操作；焦點可見；標籤、錯誤訊息可被輔助工具辨識。
- 載入、無資料、API 錯誤、送出中、成功及唯讀拒絕均有清楚呈現。
- 一般文字對比至少 4.5:1；大型文字與控制項邊界至少 3:1；狀態必須搭配文字。
- 走完本範本業務保留條件中的核心流程；執行 TypeScript、既有相關測試與正式建置。

## 開發指令範本
